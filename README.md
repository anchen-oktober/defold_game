# 🎮 Defold AI Agent Demo

## 📌 Основная задача
Показать пример Python‑агента, который заточен исключительно на работу с кодом **Defold**.

---

## 🤖 Использованные ИИ‑агенты
- **Microsoft Copilot** — для ревью и исправлений кода.  
- **Самописный AI‑агент на Python** — запущен через модель Ollama, запросы подавались из консоли.  
- **ChatGPT** — для ассетов.

## Исправления вручную
 - Перевод экранных координат в мировые через камеру
 - Замена raycast на проверку прямоугольника
 - Отключение всего объекта вместо спрайта
 - Работа с main.collection
